# Qwen3 (Dense)

Alibaba Qwen's third-generation dense language model family. Notable for deeper architectures (more transformer blocks) relative to comparable-sized models and a large 152K vocabulary for multilingual coverage.

## Key Architecture Choices

- **Deep architectures**: Qwen3 uses more transformer blocks relative to model width compared to peers. The 32B has 64 layers (same as OLMo 2 32B at d=5120), and 8B has 36 layers.
- **Consistent head dim**: all variants use d_head=128, adjusting head count and KV groups per size.
- **High RoPE theta (1M)**: supports long-context extrapolation without explicit RoPE scaling.
- **Large vocabulary (152K)**: one of the largest vocab sizes among open LLMs, supporting broad multilingual and code coverage.
- **Thinking mode**: supports toggling between "thinking" (chain-of-thought reasoning) and direct response modes at inference time.
