# Gemma 3

Google's third-generation lightweight open model family. Notable for a hybrid attention strategy combining local sliding-window and global attention layers, and dual pre-norm + post-norm RMSNorm placement.

## Key Architecture Choices

- **Hybrid local/global attention**: 5:1 ratio of sliding-window (local, 1024 tokens) to full (global) attention layers. Local layers attend only to nearby tokens, reducing compute for long contexts while periodic global layers maintain long-range dependencies.
- **Dual normalization**: applies RMSNorm both before (pre-norm) and after (post-norm) attention and FFN sublayers. This redundancy appears beneficial for training stability, combining the benefits of both placements.
- **Long context at small scale**: all variants support 128K context, achieved through the efficient local/global attention split rather than brute-force full attention.
- **Multimodal capability**: 4B+ variants support vision input via a SigLIP-based image encoder, though this note focuses on the text architecture.
