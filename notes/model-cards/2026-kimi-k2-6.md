# Kimi K2.6

Moonshot's continuation of the 1T-scale sparse MoE backbone first shipped as [[notes/model-cards/2025-kimi-k2|Kimi K2]]. Per Raschka, K2.6 is a "native-multimodal K2.5 successor" that **keeps the same 1T sparse MoE backbone** — the gains over the K2 line come from training recipe and post-training, not architectural changes. A clean example of the frontier-MoE pattern: scale + recipe, architecture roughly unchanged from DeepSeek V3.

## Key Architecture Choices

- **Same 1T MoE backbone as K2**: per Raschka, "keeps the same 1T sparse MoE backbone". 61 MLA layers matches DeepSeek V3 / V3.2's depth. The Kimi K2 → K2.5 → K2.6 line is a recipe-and-data progression, not an architecture rewrite.
- **Native multimodal**: K2.6 ships as a native-multimodal model, distinguishing it from the text-only K2 release line.
- **Long-horizon agentic positioning**: gallery framing emphasizes "long-horizon coding, design, and agent orchestration" — recipe and post-training tuned for multi-turn agent loops rather than single-shot Q&A.
- **3.2% activation ratio**: 32B active out of 1T — sparser than K2's reported active fraction, in line with the broader 2026 trend toward lower activation ratios.
