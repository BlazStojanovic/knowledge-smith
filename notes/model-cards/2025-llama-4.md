# Llama 4

Meta's fourth-generation LLM family. First Llama generation to use Mixture-of-Experts. Maverick uses interleaved dense and MoE layers with large experts.

## Key Architecture Choices

- **Interleaved dense/MoE**: alternates between dense FFN layers and MoE layers rather than using MoE on every layer. This differs from DeepSeek V3 (MoE on all but first 3 layers) and Qwen3 MoE (MoE on every layer).
- **Large experts**: Raschka describes Llama 4 as using fewer, larger experts compared to DeepSeek V3 or Qwen3 MoE, making this a "classic" MoE approach.
- **Same active params across variants**: both Scout and Maverick activate ~17B parameters per token despite very different total sizes. The scaling comes from expert count and layer count.
- **Multimodal**: native vision support via an image encoder, though this note focuses on text architecture.

> [!warning] unverified
> Raschka article states "8 large experts, 2 active per token" for Maverick, but the HuggingFace model name includes "128E" suggesting 128 experts. The exact expert configuration needs verification from the official technical report.
