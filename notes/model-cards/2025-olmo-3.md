# OLMo 3

Allen AI's third-generation fully open language model. Continues the post-norm RMSNorm approach from OLMo 2, adds sliding-window attention and YaRN-based context extension to 64K tokens. Fully open-source with detailed training reports.

## Key Architecture Choices

- **Post-norm RMSNorm (continued from OLMo 2)**: normalization after attention/FFN sublayers for training stability. See [[notes/model-cards/2025-olmo-2]].
- **Sliding window attention**: local attention window for efficient long-context processing, complementing the global attention capability.
- **YaRN context extension**: extends native context from shorter pretraining length to 64K tokens using YaRN RoPE scaling.
- **MHA→GQA scaling**: 7B uses full MHA; 32B uses GQA for inference efficiency — same pattern as OLMo 2.
- **Fully open**: training data, code, intermediate checkpoints, and evaluation code all publicly released with detailed training reports.
