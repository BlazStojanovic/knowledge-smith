# Gemma 4

Google's fourth-generation open Gemma model. Continues the hybrid local/global attention recipe from Gemma 3 with sliding-window local layers and periodic global layers, extended to 256K context. Multimodal checkpoint at release.

## Architecture

Source: Raschka LLM Architecture Gallery card.

| Property | Value |
|---|---|
| Parameters (total) | 30.7B |
| Layers (total) | 60 (50 sliding-window + 10 global) |
| Attention | GQA with QK-Norm; unified K/V on global layers; 5:1 sliding-window-to-global ratio |
| Positional encoding | p-RoPE on global layers |
| Normalization | RMSNorm — Gemma's pre/post-norm dual placement (carried from Gemma 3) |
| Activation | GELU |
| Vocab size | 262,144 (~262K) |
| Max context length | 256,000 |
| KV cache (per Raschka) | 840 KiB · "very high" class |

Per-variant dims (hidden, FFN, attn heads, KV heads, head dim) [nv] — gallery does not list them.

## Key Architecture Choices

- **Hybrid local/global attention, 5:1 ratio**: 50 sliding-window layers per 10 global layers. Same recipe as [[notes/model-cards/2025-gemma-3]]; the cheap path for extending context without full-attention compute, with periodic global layers to maintain long-range dependencies.
- **p-RoPE on global layers only**: partial RoPE applied only to the global-attention layers — locally-scoped layers presumably use a different (or no) positional encoding. Specifics of the partial-RoPE split [nv].
- **Unified K/V on global layers**: gallery flags this as a distinct property of the global layers; mechanism not explained in gallery (likely K/V sharing across heads or layers).
- **Pre/post-norm carried over**: keeps Gemma's dual RMSNorm placement (both before and after attention/FFN sublayers), a Gemma-family signature.
- **256K native context**: 2× Gemma 3's 128K, achieved through the sliding-window/global mix rather than brute-force full attention.
- **Multimodal at release**: shipped as a multimodal checkpoint, like Gemma 3 4B+.
