# GLM-4.5

Zhipu AI's flagship MoE model. Notable for using dense initial layers (first 3) before MoE routing begins, and for incorporating attention bias — both relatively uncommon design choices shared with gpt-oss.

## Key Architecture Choices

- **Dense initial layers (first 3)**: same pattern as DeepSeek V3 (first_k_dense_replace=3) — establishes low-level representations with full-capacity dense FFN before MoE routing begins. Benefits training stability.
- **Attention bias**: uses bias terms in attention layers, shared with gpt-oss but uncommon elsewhere. Most contemporary LLMs disable attention bias.
- **Two-tier sizing**: 355B flagship and 106B "Air" variant, presumably with different expert counts or layer depths for different deployment targets.
