# Kimi K2

Moonshot AI's flagship MoE model. At 1 trillion parameters, the largest open-weight LLM at release. Based on DeepSeek V3's MoE/MLA architecture with more experts and fewer MLA heads. Notable for using the Muon optimizer instead of AdamW.

Kimi K2 Thinking uses the same architecture with extended context (256K).

## Key Architecture Choices

- **DeepSeek V3 derivative**: builds on V3's MLA + MoE architecture, demonstrating that the V3 blueprint scales to 1T+ parameters.
- **More experts, fewer MLA heads**: compared to V3, K2 increases expert count and reduces the number of MLA attention heads. Exact counts need verification.
- **Muon optimizer**: uses Muon instead of AdamW for training, reportedly achieving exceptional training loss curves. This is a training-recipe innovation rather than architectural, but it's architecturally relevant because optimizer choice can constrain architecture design.
- **Dense initial layers**: follows the pattern (also seen in DeepSeek V3 and GLM-4.5) of using dense layers before MoE routing begins.
- **K2 Thinking**: extends context from 128K to 256K tokens with chain-of-thought reasoning capability. Same architecture, different training and context handling.
