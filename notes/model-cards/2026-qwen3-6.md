# Qwen3.6

Alibaba Qwen's continuation of the [[notes/model-cards/2025-qwen3-next|Qwen3-Next]] / Qwen3.5 hybrid-attention recipe: mostly Gated DeltaNet (linear-attention-style) layers with periodic Gated full-attention layers, 3:1 ratio. The 3.6 release introduces a new **27B dense** variant alongside the 35B-A3B sparse MoE variant.

## Key Architecture Choices

- **Hybrid linear/full attention, 3:1**: mostly Gated DeltaNet (linear-attention variant) layers with periodic Gated full-attention layers. Same recipe as [[notes/model-cards/2025-qwen3-next]] and [[notes/model-cards/2025-kimi-linear]] — the now-dominant pattern for cheap long-context throughput.
- **New dense variant**: 27B dense hybrid is a notable departure from Qwen3-Next's MoE-only positioning. 64-layer hybrid stack (48 DeltaNet + 16 full attention) suggests dense + hybrid attention is competitive with sparse MoE at the 30B class.
- **Expert reshuffle in 35B-A3B**: 256 experts with 8 routed + 1 shared per token. Compare to [[notes/model-cards/2025-qwen3-next]] (1024 experts, 3 active, shared) — Qwen3.6 MoE walks back the extreme expert count, settling closer to DeepSeek's 256 routed + shared scheme.
- **262K native context**: held flat from Qwen3-Next, sufficient for long-document agentic workloads without 1M-context overhead.
