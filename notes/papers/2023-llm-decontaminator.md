# Rethinking Benchmark and Contamination for Language Models with Rephrased Samples

Demonstrates that simple variations (paraphrasing, translation) bypass standard n-gram decontamination; proposes LLM-based decontamination.

- **Authors**: Shuo Yang, Wei-Lin Chiang, Lianmin Zheng, Joseph E. Gonzalez, Ion Stoica
- **Venue**: arXiv 2023
- **arXiv**: [2311.04850](https://arxiv.org/abs/2311.04850)
- **Raw**: [[raw/papers/pdf/2023-llm-decontaminator]]

## Core contribution

Shows that standard n-gram overlap decontamination is brittle: paraphrased or translated test items pass through. Proposes using an LLM to detect semantic overlap between training and test data. Identifies previously unknown overlaps in MMLU, GSM8K, and HumanEval, including in synthetic datasets created by GPT-3.5/4.

## Key implications

- N-gram decontamination is necessary but insufficient
- Teacher-model leakage: synthetic data generated by GPT-3.5/4 can carry contamination from the teacher's training data
- LLM-based semantic matching catches rephrased contamination that string matching misses
