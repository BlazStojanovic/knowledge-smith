# ToolBench: An Open Platform for Training, Serving, and Evaluating Large Language Model Tool Learning

## Citation

- URL: https://arxiv.org/abs/2305.16504
- PDF: https://arxiv.org/pdf/2305.16504
- Authors: Yujia Qin, Shihao Liang, Yining Ye, Kunlun Zhu, Lan Yan, Yaxi Lu, Yankai Lin, Xin Cong, Xiangru Tang, Bill Qian, Sihan Zhao, Lauren Hong, Runchu Tian, Ruobing Xie, Jie Zhou, Mark Gerstein, Dahai Li, Zhiyuan Liu, Maosong Sun
- Year / venue: 2023 (ICLR 2024)
- arXiv: 2305.16504

## Short Summary

Large-scale benchmark for tool-using LLMs. 16K real-world REST APIs from RapidAPI, 125K training instances generated by ChatGPT requiring 1–5 API calls each. Introduces ToolLLaMA trained on this data and StableToolBench for reproducible evaluation. Used as primary benchmark in [[notes/papers/2024-quality-matters-evaluating-synthetic-data-for-tool-using-llms]], where 84% of instances were found to contain errors.

## Relevance To Poolside

Our interpretation: keep this as an unread source for future grounding. Primary dataset for tool-use quality evaluation. The quality findings in [[notes/papers/2024-quality-matters-evaluating-synthetic-data-for-tool-using-llms]] suggest that ToolBench data should not be used uncritically.
