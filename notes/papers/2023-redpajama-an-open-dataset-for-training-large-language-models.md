# RedPajama: An Open Dataset for Training Large Language Models

Open reproduction of the LLaMA training dataset with transparent sourcing.

- **Authors**: Together Computer
- **Year**: 2023
- **URL**: [together.ai/blog/redpajama](https://www.together.ai/blog/redpajama)

## Core contribution

Open reproduction of the LLaMA pretraining data recipe. Provides 1.2T tokens across Common Crawl, C4, GitHub, Wikipedia, books, ArXiv, and StackExchange with documented processing.
