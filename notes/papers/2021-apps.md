# Measuring Coding Challenge Competence With APPS

Introduces APPS benchmark: 10,000 coding problems spanning introductory to competition-level difficulty, evaluated via test case execution.

- **Authors**: Dan Hendrycks, Steven Basart, Saurav Kadavath, Mantas Mazeika, Akul Arora, Ethan Guo, Collin Burns, Samir Puranik, Horace He, Dawn Song, Jacob Steinhardt
- **Venue**: NeurIPS 2021
- **arXiv**: [2105.09938](https://arxiv.org/abs/2105.09938)
- **Raw**: [[raw/papers/pdf/2021-apps]]

## Core contribution

APPS: 10,000 coding problems with three difficulty levels (introductory / interview / competition). Each problem has natural language specification + test cases. Sourced from open-access coding websites.

## Key results

- GPT-Neo achieves ~20% on introductory-level test cases
- Syntax errors decrease exponentially with model size
- Even the largest models struggle with competition-level problems

## Methodological relevance

- **Difficulty stratification**: explicit 3-level difficulty enables tracking improvement curves per difficulty tier
- **Execution-based evaluation**: pass rate over test cases
- **Scale**: 10,000 problems provides better statistical power than HumanEval (164) or MBPP (974)
