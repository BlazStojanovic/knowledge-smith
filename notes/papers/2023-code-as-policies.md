# Code as Policies: Language Model Programs for Embodied Control

## Citation

- URL: https://arxiv.org/abs/2209.07753
- PDF: https://arxiv.org/pdf/2209.07753
- Authors: Jacky Liang, Wenlong Huang, Fei Xia, et al.
- Year / venue: 2023
- arXiv: 2209.07753

## Core Claim

LLMs generate executable robot policy code from natural language instructions, producing programmatic control policies that can be directly run on robotic platforms. Execution traces from these policies provide states, actions, and failures for analysis or distillation.
