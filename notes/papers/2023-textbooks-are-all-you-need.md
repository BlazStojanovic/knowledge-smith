# Textbooks Are All You Need (phi-1)

- **arXiv**: [2306.11644](https://arxiv.org/abs/2306.11644)
- **Authors / affiliation**: Suriya Gunasekar, Yi Zhang, Jyoti Aneja et al. (Microsoft Research)
- **Year / venue**: 2023
- **Raw**: [[raw/papers/pdf/2023-textbooks-are-all-you-need]]
- **Grounding axis**: [[maps/grounding/ungrounded-seed]] — topic/role-prompt conditioned generation (Axis 1)

## Method

Trains phi-1 (1.3B) on two synthetic data sources generated by GPT-3.5:

1. **"Textbook" prose** — Python tutorials conditioned on topic + target-audience prompts.
2. **CodeExercises** — coding exercises conditioned on topic + concept prompts.

A GPT-4 educational-quality classifier filters web-crawled code (The Stack, StackOverflow) to select a "textbook quality" subset. Total training: ~7B tokens (6B filtered web + 1B synthetic). 4 days on 8 A100s.

Core claim: data quality dominates data quantity — a 1.3B model trained on high-quality synthetic data can match or exceed much larger models on code benchmarks.

## Notes

- Canonical example of ungrounded seed-prompt synthesis for code: generation is conditioned on a topic distribution, not on retrieved code. Contrast with execution-grounded pipelines (SWE-Gym, AceCoder) where the verifier is a test runner.
- **Contamination caveat**: subsequent audits found CodeExercises items near-duplicate HumanEval problems. Treat absolute HumanEval/MBPP numbers with caution; see note in [[maps/grounding/landscape]] and [[maps/grounding/ungrounded-seed]].
- The "textbook quality" framing influenced Cosmopedia ([[notes/papers/2024-cosmopedia]]) and later large-scale synthetic pretrain pipelines.
