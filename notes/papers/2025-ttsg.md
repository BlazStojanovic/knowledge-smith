# Traffic Scene Generation from Natural Language Description for Autonomous Vehicles with Large Language Model

## Citation

- URL: https://arxiv.org/abs/2409.09575
- PDF: https://arxiv.org/pdf/2409.09575

## Core Claim

LLM-based text-to-traffic-scene generation pipeline evaluated on CARLA; introduces agent diversity (AD) and road diversity (RD) metrics alongside text-matching correctness and collision-based safety.
