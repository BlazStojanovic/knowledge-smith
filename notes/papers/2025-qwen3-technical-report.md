# Qwen3 Technical Report

## Short Summary

Technical report for the Qwen3 model family. Dense + MoE architectures, 0.6B–235B parameters. Key innovation: unified thinking/non-thinking mode (no need to switch between separate models); thinking budget mechanism for adaptive compute at inference. Expands multilingual support from 29 to 119 languages vs. Qwen2.5. State-of-the-art on code, math, and agent tasks. Apache 2.0.
