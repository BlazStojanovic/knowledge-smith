# Synthetic Data Generation Using Large Language Models: Advances in Text and Code

## Citation

- URL: https://arxiv.org/abs/2503.14023
- PDF: https://arxiv.org/pdf/2503.14023
- Authors: Mihai Nadas, Laura Diosan, Andreea Tomescu
- Year / venue: 2025 (arXiv, March 2025)

## Core Claim

Survey of LLM-based synthetic data generation for text and code tasks. Covers prompt-based generation, retrieval-augmented pipelines, low-resource classification, and code-centric applications. Identifies open challenges: factual accuracy, distributional realism, bias amplification, and evaluation gaps.

## Key Paper Ideas

- **Techniques surveyed.** Prompt-based generation, RAG-augmented pipelines, self-play / iterative refinement, task-specific conditioning — across text and code domains.
- **Low-resource applications.** Synthetic data as a solution for classification tasks with insufficient real training signal.
- **Code-centric generation.** Dedicated coverage of code synthesis as a distinct sub-problem with its own quality criteria.
- **Challenges.** Factual inaccuracies, distributional shift vs. real data, potential amplification of LLM biases.
- **Future directions.** Automated prompt engineering and evaluation frameworks for synthetic data quality.
