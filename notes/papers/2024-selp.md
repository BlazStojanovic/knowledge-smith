# SELP: Generating Safe and Efficient Task Plans for Robot Agents with Large Language Models

## Core Claim

Translates natural-language tasks into Linear Temporal Logic (LTL) specifications using equivalence voting for robustness, then enforces safety constraints during plan generation via constrained decoding guided by automata.
