# Surge Phenomenon in Optimal Learning Rate and Batch Size Scaling

## Citation

- URL: https://arxiv.org/abs/2405.14578
- Authors: Shuaipeng Li et al.
- Year / venue: 2024 / NeurIPS 2024
- arXiv: 2405.14578

## Core Claim

The optimal learning rate as a function of batch size is non-monotonic for Adam-style optimizers: it rises then falls (a "surge"). Neither linear nor square root scaling rules are universally correct for adaptive optimizers.
