# Paper Notes

Paper notes are grounded in a single paper. Keep paper claims separate from Poolside interpretation.

## Naming

Use `year-slug.md`.

Examples:

- `2023-scaling-data-constrained-language-models.md`
- `2024-example-paper-title.md`

Use the original publication/preprint year when that is the cited source. Record later journal versions in the citation section.

## Raw Sources

Store local PDFs and source notes under `raw/papers/` with the same `year-slug` prefix when possible.

Example:

- `raw/papers/2023-scaling-data-constrained-language-models.pdf`
- `raw/papers/2023-scaling-data-constrained-language-models.notes.md`
- `raw/papers/2023-scaling-data-constrained-language-models.html`

Use `read/unread` until Blaz marks a paper as read.

When upgrading a paper note, use [[skills/paper-reading/SKILL]] and store reusable figures under `raw/images/papers/<year-slug>/`.
