# Model Cards

External model cards, system cards, and release cards live here. Keep them separate from `models/`, which is reserved for current Poolside model notes.

## Naming

Use `year-slug.md`.

Examples:

- `2026-claude-mythos-preview-system-card.md`
- `2025-olmo-3.md`

## Raw Sources

Store mirrored PDFs under `raw/model-cards/` with the same `year-slug` prefix when possible.
