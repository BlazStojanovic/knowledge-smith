# Paper Images

Reusable figures extracted from papers.

Use one folder per paper:

- `raw/images/papers/<year-slug>/figure-01.png`
- `raw/images/papers/<year-slug>/manifest.md`

Each manifest should record the figure source, caption, paper section, and note link where the figure is used.
