###### Abstract

What are the limits of controlling language models via synthetic training data? We develop a reinforcement learning (RL) primitive, the Dataset Policy Gradient (DPG), which can precisely optimize synthetic data generators to produce a dataset of targeted examples. When used for supervised fine-tuning (SFT) of a target model, these examples cause the target model to do well on a differentiable metric of our choice. Our approach achieves this by taking exact data attribution via higher-order gradients and using those scores as policy gradient rewards. We prove that this procedure closely approximates the true, intractable gradient for the synthetic data generator.
To illustrate the potential of DPG, we show that, using only SFT on generated examples, we can cause the target model’s LM head weights to
(1) embed a QR code, (2) embed the pattern 67, and (3) have lower ℓ2\ell^{2} norm. We additionally show that we can cause the generator to (4) rephrase inputs in a new language and (5) produce a specific UUID, even though neither of these objectives is conveyed in the generator’s input prompts.
These findings suggest that DPG is a powerful and flexible technique for shaping model properties using only synthetic training examples.

## 1 Introduction

Synthetic training data has recently gained significant interest (wang2023selfinstructaligninglanguagemodels; alpaca; yang2025synthetic; ruan2025reasoninglearnlatentthoughts) but how finely can we control synthetic data generation? It is well-attested that training examples (real and synthetic) can communicate unexpected information to language models even in the context of simple supervised fine-tuning (SFT). Recent prominent examples include emergent misalignment (betley2026emergent; chua2025thought), subliminal learning (cloud2025subliminal; betley2025weird), data poisoning from harmless inputs (kong2025revisiting), and model provenance (kuditipudi2025blackbox). Is there a way to tractably train a synthetic data generator that produces training data targeting any phenomena we choose?

Intuitively, straightforward reinforcement learning techniques could be used to optimize synthetic data generators directly for downstream metrics. Every time a dataset is generated by our policy, we could train a model on it and measure a metric of interest from the model. We could then use this metric as a single reward for the entire dataset and perform a policy gradient step. However, this approach is computationally prohibitive because it provides only a single reward for a full run of inner target model training and evaluation.

In this work, we present the Dataset Policy Gradient (DPG), a principled RL approach that enables us to generate synthetic training data for any differentiable downstream target. With our method, rewards are at the level of individual synthetic texts, instead of the dataset level. This method opens the door to a wide range of applications in which training examples are chosen or synthesized with the goal of imbuing a target model with a specific property.

Our approach leverages the meta-learning results of raghu2021metalearning, and the recent improvements from engstrom2025metagradients. These papers demonstrate how to compute metagradients (gradients of hyperparameters of the training process) tractably at the scale of LLM training.
The metagradient enables backpropagation from a differentiable post-training metric (e.g., loss on a benchmark) to parameters of the training process (e.g., optimization hyperparameters such as learning rate schedules).
Importantly, it is also tractable to compute metagradients for training example weights, if training occurs with a data-weighted loss.
This leads to the key insight for our method:
we can incorporate this metagradient-based data valuation approach into an RL procedure to generate targeted synthetic training data.

The DPG approach is a flexible framework.

We seek to test the limits of our method by experimenting with unusual choices of Φ\Phi. In our first experiments, we demonstrate that the generator produces examples that have a specific effect on the target model: encoding a QR code ([Section 4.1](#S4.SS1 "4.1 Encoding a QR Code in a Target Model’s LM Head ‣ 4 Results ‣ Synthetic Data for any Differentiable Target")) and the pattern 67 ([Section 4.2](#S4.SS2 "4.2 Encoding 67 in a Target Model’s LM Head ‣ 4 Results ‣ Synthetic Data for any Differentiable Target")) in the LM head weights of the target model, and lowering the ℓ2\ell^{2} norm of the LM head weights ([Section 4.3](#S4.SS3 "4.3 Adjusting the Norm of Target Model Weights ‣ 4 Results ‣ Synthetic Data for any Differentiable Target")). We then directly assess the generator, showing that the Dataset Policy Gradient can guide it to rephrase Wikipedia articles in a new language ([Section 4.4](#S4.SS4 "4.4 Interpreting the Generated Data when Targeting Multilingual Validation Loss ‣ 4 Results ‣ Synthetic Data for any Differentiable Target")) and produce a specific UUID ([Section 4.5](#S4.SS5 "4.5 Interpreting the Generated Data when Targeting Loss on a UUID ‣ 4 Results ‣ Synthetic Data for any Differentiable Target")), without any prompting for these behaviors.

In our experiments, we perform ablations to disentangle which aspects of the metagradient computation are essential in driving performance. For our QR code, 67, and ℓ2\ell^{2} norm experiments, we find that computing metagradients with respect to several gradient descent steps of target model training is helpful. For the other experiments, we used a larger model as our target model and only tried one step of target model training for metagradient computation, due to compute constraints.
We also find that the choice of target model optimizer (Adam vs. SGD) in the computation of the metagradient is a significant factor. Where we used SGD in learning algorithm 𝒜\mathcal{A} ([Figure 1](#S1.F1 "In 1 Introduction ‣ Synthetic Data for any Differentiable Target")), the trained generator’s synthetic data did not cause the target model to perform well on Φ\Phi (even if Adam was used in after-the-fact training of the target model), whereas Adam is successful in this role. In the single step case for SGD, the metagradient reduces to standard gradient-of-target and gradient-of-train dot-product approximations to influence functions (koh2017influence). By contrast, where Adam is the optimizer, there are additional terms which make the metagradient different from approximations to typical influence functions, even in the single-step case. This indicates that full metagradients are critical to optimizing the generator.

Overall, our results provide evidence that the DPG framework allows for a new level of fine-grained control in synthetic training data generation, for the purpose of imbuing downstream models with specific properties – both desirable and undesirable.

## 2 Related Work

#### Synthetic data for language model training.

Synthetic data is increasingly viewed as a key resource for language model performance gains (wang2023selfinstructaligninglanguagemodels; alpaca; maini2024rephrasingwebrecipecompute; abdin2024phi4technicalreport; ruan2025reasoninglearnlatentthoughts; yang2025syntheticbootstrappedpretraining). Our contribution is orthogonal: instead of asking what synthetic data heuristics improve performance, we study how precisely synthetic data can be optimized – via metagradients – to induce targeted and even unconventional differentiable properties in trained models.

#### Training data attribution.

We benefit from work attributing model behavior to individual training examples. Influence functions (Hampel\_1974; koh2017influence; bae2022influence) provide local estimates of how upweighting a training datum affects downstream performance. Recent work scales attribution ideas to modern LMs and multi-step training (raghu2021metalearning; pmlr-v162-ilyas22a; pmlr-v202-park23c; grosse2023studyinglargelanguagemodel; xia2024lessselectinginfluentialdata; thrush2025improvingpretrainingdatausing; thudi2025mixminfindingdatamixtures; engstrom2025metagradients; calian2025dataratermetalearneddatasetcuration). Data attribution is a subroutine in our work: we leverage the metagradients approach from engstrom2025metagradients to assign rewards to synthetic training examples generated by an RL policy.

#### Optimizing and editing training data.

We focus on generating discrete synthetic training data from scratch. Other work has focused on targeted optimization of perturbations in differentiable training data, such as perturbing existing images (such2019generativeteachingnetworksaccelerating; wang2020datasetdistillation; huang2021metapoisonpracticalgeneralpurposecleanlabel; rosser2026infusionshapingmodelbehavior). In the discrete data space, recent work includes RL approaches where models iteratively improve by generating synthetic training data for themselves, or through generating some other self-edit. In SEAL (zweiger2025selfadaptinglanguagemodels) LLMs generate candidate self-edits (directives on how to update their own weights); these directives are carried out and edited LLMs are evaluated on downstream tasks. The performances of the edited LLMs are used directly as RL rewards, but this is intractable for our data generation tasks. MASS (kaya2026testtimemetaadaptationselfsynthesis) performs bilevel meta-adaptation using self-synthesized data at test time, computing a training data metagradient within an RL loop. MASS focuses on single datum adaptation at test time and computes the metagradient in the local one-train-step case without taking into account optimizer dynamics, analogous to an influence function approximation which lacks the more general metagradient critical for our tasks. In contrast to these methods, we prove that per-step metagradients provide accurate gradient signals that approximate the intractable full RL problem. Then, we optimize a policy that produces an entirely new training dataset targeting arbitrary differentiable training or post-training properties of an arbitrary target model over multiple training steps, taking into account arbitrary optimizers such as Adam (kingma2015adam).

#### Optimizing inference data.

Several approaches optimize prompts to elicit targeted behaviors at inference time (zou2023universaltransferableadversarialattacks; zhou2023largelanguagemodelshumanlevel; agrawal2026gepareflectivepromptevolution). We instead optimize the generation of training data, so that learning itself induces desired behaviors.

## 3 Methods

We train a policy (i.e. the generator, πθ\pi\_{\theta}) to generate training data for another model (i.e. the target model, trained in the RL loop within 𝒜\mathcal{A}). The objective is to generate synthetic data DD that increases the metric, Φ​(𝒜​(D))\Phi(\mathcal{A}(D)). Formally, we want to optimize πθ\pi\_{\theta} via the objective

|  |  |  |
| --- | --- | --- |
|  | maxπθ⁡𝔼D∼πθ​[Φ​(𝒜​(D))],\max\_{\pi\_{\theta}}\mathbb{E}\_{D\sim\pi\_{\theta}}[\Phi(\mathcal{A}(D))], |  |

but a direct approach is expensive: it involves a single RL reward over a dataset instead of a reward for each example in the dataset. In principle, the computational cost could be thousands of times greater than a typical LM RL problem. Could we reduce this to a typical, per-example, RL problem?
Ideally, we want per-example rewards r​(x)r(x), for xx in DD, such that:

|  |  |  |
| --- | --- | --- |
|  | ∇θ𝔼D∼πθ​[Φ​(𝒜​(D))]=𝔼D∼πθ​[∑x∈Dr​(x)​∇θlog⁡πθ​(x)].\nabla\_{\theta}\mathbb{E}\_{D\sim\pi\_{\theta}}[\Phi(\mathcal{A}(D))]=\mathbb{E}\_{D\sim\pi\_{\theta}}\left[\sum\_{x\in D}r(x)\nabla\_{\theta}\log\pi\_{\theta}(x)\right]. |  |

That is, taking a policy gradient step with respect to our per-example reward is equivalent to taking the intractable policy gradient step. This turns out to be possible and tractable. If r​(x)r(x) is defined as the exact influence of example xx on the reward Φ​(𝒜​(D))\Phi(\mathcal{A}(D)) through the training process, then the per-example policy gradient closely approximates the dataset-level policy gradient. In the next sections, we elaborate on how to take this exact influence (Section [3.1](#S3.SS1 "3.1 Algorithm ‣ 3 Methods ‣ Synthetic Data for any Differentiable Target")) and prove that this approximation is valid under natural assumptions (Section [3.2](#S3.SS2 "3.2 Theory ‣ 3 Methods ‣ Synthetic Data for any Differentiable Target")).

### 3.1 Algorithm

For our experiments, we use Group Relative Policy Optimization (GRPO) to train the generator (shao2024grpo), as shown in Algorithm [1](#alg1 "Algorithm 1 ‣ 3.1 Algorithm ‣ 3 Methods ‣ Synthetic Data for any Differentiable Target"). For every outer GRPO step, we can divide the set of policy generations into GG training sets for a target model within the GRPO reward function. Optionally, we can also choose to do cross group batching, combining all of these training sets into one training set, and running target model training once – this is more efficient. We run the inner target model training loop for potentially several optimization steps, with loss defined as

|  |  |  |

|  | wi​ℓ​(ϕ,xi),w\_{i}\ell(\phi,x\_{i}), |  |

Using the approach from engstrom2025metagradients, we compute the gradient for these data weights:

A larger gradient for an example’s weight tells us that training on this example would improve the target metric more than training on an example with a smaller gradient. Motivated by this intuition, we use this gradient as the reward for our generator. In the following section, we provide a theoretical justification for this choice.

### 3.2 Theory

In our theory, we analyze a simplified variant of Algorithm [1](#alg1 "Algorithm 1 ‣ 3.1 Algorithm ‣ 3 Methods ‣ Synthetic Data for any Differentiable Target") which replaces GRPO with the vanilla policy gradient update and optimizes the target model with stochastic gradient descent (SGD). We use the metagradient computation method from engstrom2025metagradients to get 𝝉D≔∇𝒘Φ​(𝒜​(𝒘,D))\bm{\tau}\_{D}\coloneq\nabla\_{\bm{w}}\Phi(\mathcal{A}(\bm{w},D)), where 𝒜​(𝒘,D)\mathcal{A}(\bm{w},D) is a learning algorithm that trains a target model on an nn-sample dataset DD with per-example weighted loss given by weights 𝒘\bm{w}. We generate DD by sampling from a policy, and we use our metagradient as the reward signal. Treating the τi\tau\_{i} as per-example rewards, we take the policy gradient step given by 𝒢=τi​∇θlog⁡πθ​(xi)\mathcal{G}=\tau\_{i}\nabla\_{\theta}\log\pi\_{\theta}(x\_{i}).

Now, let F​(θ)≔𝔼D∼πθ​[Φ​(𝒜​(D))]F(\theta)\coloneq\mathbb{E}\_{D\sim\pi\_{\theta}}[\Phi(\mathcal{A}(D))]. FF is the target performance of a model trained on samples from πθ\pi\_{\theta}. Taking gradient steps on FF directly optimizes for our target, but this does not give us example-level rewards and it is not tractable in any of our experiments.

Now, let F′​(θ,p)≔𝔼D∼p​[Φ​(𝒜​(πθ/p,D))]F^{\prime}(\theta,p)\coloneq\mathbb{E}\_{D\sim p}[\Phi(\mathcal{A}(\pi\_{\theta}/p,D))].
Note that F′F^{\prime} is the surrogate that we actually optimize in our DPG setup. Setting wi​(θ)=πθ​(xi)p​(xi)w\_{i}(\theta)=\frac{\pi\_{\theta}(x\_{i})}{p(x\_{i})} and using the chain rule, we have:

|  |  |  |
| --- | --- | --- |
|  | ∇θF′​(θ,p)=𝔼D∼p​[∑i=1n∂∂wi​Φ​(𝒜​(𝒘,D))​πθ​(xi)p​(xi)​∇θlog⁡πθ​(xi)]\displaystyle\nabla\_{\theta}F^{\prime}(\theta,p)=\mathbb{E}\_{D\sim p}\left[\sum\_{i=1}^{n}\frac{\partial}{\partial w\_{i}}\Phi(\mathcal{A}(\bm{w},D))\frac{\pi\_{\theta}(x\_{i})}{p(x\_{i})}\nabla\_{\theta}\log\pi\_{\theta}(x\_{i})\right] |  |

Setting πθ=p=πθ0\pi\_{\theta}=p=\pi\_{\theta\_{0}}, we see the metagradient update 𝒢\mathcal{G} is an unbiased stochastic gradient for F′F^{\prime}. Via the following theorem, ∇θF′\nabla\_{\theta}F^{\prime} accurately approximates the ideal gradient: ∇θF\nabla\_{\theta}F.

Under suitable regularity conditions on smoothness (Appendix [A](#A1 "Appendix A Proofs ‣ Synthetic Data for any Differentiable Target"), A1-A8), we have:

|  |  |  |

N.B. – although it may be clear to some, the notation can be tricky to keep straight. In this equation, we take the gradient of F′F^{\prime} with respect to only the first argument, evaluated at θ0\theta\_{0}, with pp set to πθ0\pi\_{\theta\_{0}}.

See Appendix [A](#A1 "Appendix A Proofs ‣ Synthetic Data for any Differentiable Target") for a proof. This theorem shows that, under first and second order smoothness assumptions listed in Appendix [A](#A1 "Appendix A Proofs ‣ Synthetic Data for any Differentiable Target"), our metagradient reward policy gradient can approximate the desired policy gradient for the generator if 𝒜\mathcal{A} has the following properties: the batch size is large, and step size is small relative to the number of training steps.

It is important to note that, even though our theorem assumes SGD, we find experimentally that it is essential to use Adam (kingma2015adam) to train the target model in the computation of the metagradient. This remains true even when we use only a single step of target model training to compute the metagradient. We conjecture that using Adam, like SGD, would also result in a reasonable bound via supθ0‖∇θF​(θ0)−∇θF′​(θ0,πθ0)‖\sup\_{\theta\_{0}}||\nabla\_{\theta}F(\theta\_{0})-\nabla\_{\theta}F^{\prime}(\theta\_{0},\pi\_{\theta\_{0}})||, but still with some error: like SGD’s behavior, Adam’s behavior depends on the second moment of the target model’s loss gradient (which is different between FF and F′F^{\prime}).

## 4 Results

We present experiments where we train synthetic data generators to target various metrics downstream of training a target model. We first validate our pipeline end-to-end, generating synthetic train data that can precisely manipulate the weights of target models. We then analyze the generator’s output to determine whether the synthetic data is interpretable.

In all of our experiments, the generator is initialized from Llama 3.2 Instruct (grattafiori2024llama3herdmodels) and given Wikipedia111Accessed in 2025 via <https://huggingface.co/datasets/wikimedia/wikipedia> articles to paraphrase (prompt in Appendix [G](#A7 "Appendix G Wikipedia Paraphrase Prompt ‣ Synthetic Data for any Differentiable Target")). It then learns through Dataset Policy Gradients, optimizing its paraphrases, DD, to target a differentiable metric Φ\Phi of a learning algorithm 𝒜​(D)\mathcal{A}(D). The target model in 𝒜\mathcal{A} is initialized from Llama 3.2 Instruct as well, or GPT-2 (radford2019language), depending on the experiment. GPT-2 is used in experiments with several 𝒜\mathcal{A} training steps, where our compute constraints required us to use a smaller model. All experiments use the instance of the DPG framework with GRPO and cross group batching (Figure [7](#A2.F7 "Figure 7 ‣ Appendix B DPG GRPO Figures ‣ Synthetic Data for any Differentiable Target")), unless stated otherwise. The naive baseline never uses cross group batching (to get more reward signal) and also treats every example as coming from the same group for computing advantages (otherwise, the advantage calculation would render the rewards useless). All validations use Wikipedia articles not seen during training, unless stated otherwise. Hyperparameters for all experiments are in Appendix [E](#A5 "Appendix E Hypermarameters ‣ Synthetic Data for any Differentiable Target").

We explored training the target model with both Adam and SGD for metagradient computation. For SGD, we tried up to 14 learning rates (LRs) starting at 1e-6, and increasing by factors of 2, until we found the optimal LR against final validation loss for each task. We did the same tuning for the naive approach of using Φ\Phi as the reward (which uses Adam to train the target model but does not compute metagradients), and other baselines. There was no need to tune the LR for the metagradients + Adam approach.

Wherever we trained our generator via SGD in 𝒜\mathcal{A}, we also used SGD in target model training to get validation results. The one exception is in Appendix [C](#A3 "Appendix C Multilingual CPT Evaluation Results ‣ Synthetic Data for any Differentiable Target"), where we trained a generator using SGD in 𝒜\mathcal{A}, but validated its synthetic data by training a target model with Adam.

## 5 Conclusion

We introduced the Dataset Policy Gradient, a new RL primitive for generating synthetic training data that can be optimized for any differentiable training or post-training target metric. We also presented theoretical arguments that DPG RL keeps the policy gradient close to the ideal policy gradient, under typical assumptions. We then showcased that synthetic training data generated using DPG RL can draw images in LLM weights, alter the ℓ2\ell^{2} norm of LLM weights, and target LLM benchmarks, all through standard SFT. Interestingly, it was important to use Adam inside of 𝒜\mathcal{A} for the computation of metagradients. This suggests that it could be useful to revisit influence function results (koh2017influence), which typically ignore the optimizer and the learning trajectory. Overall, this new framework for optimizing synthetic training data allows us to reach a new level of fine-grained targeting.

## Implications

DPG may enable practitioners to intentionally steer models toward desirable capabilities using synthetic SFT examples. At the same time, this level of control has potential risks. If synthetic data generation can be optimized to induce arbitrary differentiable properties in trained models, adversaries could potentially craft subtle data poisoning attacks that target specific biases or behaviors. Understanding both the capabilities and risks of targeted synthetic data generation will be important as synthetic data becomes an increasingly central component of modern machine learning pipelines.

}

// Auxiliary function, building the preview feature when
// an inline citation is clicked
function clicked\_cite(e) {
e.preventDefault();
let cite = this.closest('.ltx\_cite');
let next = cite.nextSibling;
if (next && next.nodeType == Node.ELEMENT\_NODE && next.getAttribute('class') == "ar5iv-bibitem-preview") {
next.remove();
return; }
// Before adding a preview modal,
// cleanup older previews, in case they're still open
document.querySelectorAll('span.ar5iv-bibitem-preview').forEach(function(node) {
node.remove();
})
// Create the preview
preview = document.createElement('span');
preview.setAttribute('class','ar5iv-bibitem-preview');
let target = document.getElementById(this.getAttribute('href').slice(1));
target.childNodes.forEach(function (child) {
preview.append(child.cloneNode(true));
});
let close\_x = document.createElement('button');
close\_x.setAttribute("aria-label","Close modal for bibliography item preview");
close\_x.textContent = "×";
close\_x.setAttribute('class', 'ar5iv-button-close-preview');
close\_x.setAttribute('onclick','this.parentNode.remove()');
preview.append(close\_x);
preview.querySelectorAll('.ltx\_tag\_bibitem').forEach(function(node) {
node.remove();
});
cite.parentNode.insertBefore(preview, cite.nextSibling);
return;
}
// Global Document initialization:
// - assign the preview feature to all inline citation links
document.querySelectorAll(".ltx\_cite .ltx\_ref").forEach(function (link) {
link.addEventListener("click", clicked\_cite);
});
